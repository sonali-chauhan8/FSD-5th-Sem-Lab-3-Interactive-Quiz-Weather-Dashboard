# Lab 3 - Interactive Quiz & Weather Dashboard

This project was created as part of the Full Stack Development Lab in the 5th semester.

## Features

- Interactive 5-question quiz
- 30-second timer for each question
- Automatic score calculation
- Player name and score saving
- Leaderboard using localStorage
- Weather search by city
- Displays temperature, humidity, and weather condition
- Asynchronous API calls using JavaScript async/await and fetch()

## Technologies Used

- HTML
- CSS
- JavaScript
- localStorage
- Open-Meteo API

## Project Structure

- `index.html` - Structure of the web application
- `style.css` - Styling and layout
- `index.js` - Quiz, leaderboard, timer, and weather functionality
- `question.md` - Lab question/instructions

## How to Use

1. Open the website.
2. Attempt the quiz.
3. Select an answer and click **Next**.
4. After completing the quiz, enter your name and save your score.
5. Check the leaderboard.
6. Enter a city name in the weather section to view its current weather information.
